# 技術釣り / GIJUTU TURI

![技術釣りのロゴ](./assets/gijutu-turi-logo.png)

技術の性質を、魚の生態と釣り上げるときの抵抗として体験するWeb釣りゲーム。

本編の画面はReact版に統一しています。旧Vanilla版の海画面・エントリーポイントは残していません。`go-fish.js` などのThree.js資産は、React本編と造形確認用プレビューで共有するモデル実装です。

## 遊べる範囲

静かな海から、キャスト → アタリ → 合わせ → 巻く／緩める → Go魚またはK8s魚の捕獲まで遊べます。キャストごとに魚種が変わるローカル試作です。

- 画面いっぱいの3D海面、空の反射、緩やかな波。カメラは水中に入りません。
- 押してためる → ルアーの飛行 → 着水・波紋 → アタリに合わせる。
- 巻くと近づき、糸の張りが増加。巻きすぎると糸切れ、緩めすぎると針が外れます。
- Go魚は力をためると群れの引きに変化。K8s魚はクラスタのポッドとヘルムをまとい、重い引きとして現れます。
- 捕獲後に魚種の全身と名前を見せます。失敗時は理由とヒントを表示して再挑戦できます。
- PC画面とコントローラー画面をWebSocketで同期。実際の接続に合わせて状態を表示します。
- スマホのモーション入力と、センサーを使えない場合のタッチ操作。
- あそびかた・図鑑は必要なときだけ開くダイアログ。「景色だけを見る」で操作表示を隠せます。
- 音は明示的にオンにした場合だけ再生。PWA用manifestと静的アセットキャッシュを用意しています。

捕獲・張力・距離の判定はサーバー側で行います。リール入力は押下状態を送信し、400ms更新がなければ解除するため、通信切断で巻きっぱなしになりません。
図鑑はlocalStorage保存であり、アカウント間・端末間の永続同期は未実装です。

## 起動

### Go魚のモデル確認

サーバー起動後、[Go魚の3Dプレビュー](http://127.0.0.1:8787/go-fish.html)で形状を確認できます。
ドラッグで回転、スクロールで拡大。全身・真横・正面・ディテールの切り替え、一時停止、1→7匹の分岐表示に対応しています。
本編は捕獲まで魚の全身を表示しません。造形の参照先と実装範囲は [docs/go-fish-design.md](./docs/go-fish-design.md) に記録しています。

### 海とサーバー

Node.jsとnpmが必要です。

```powershell
npm install
npm run dev
```

[http://127.0.0.1:8787/](http://127.0.0.1:8787/) を開きます。
静的ファイルとAPIを同じサーバーから提供するため、HTMLの直接起動や静的サーバーだけでは操作できません。

## 操作

- PC: 「ここで投げてみる」またはSpaceを押してため、離して投げます。マウスの位置で左右の狙いを変えます。
- 着水後: 数秒待ってウキが沈んだら、Spaceまたは「合わせる」。アタリ前なら「巻き戻す」で中断できます。
- ファイト: Rまたはリールボタンを押し続けると巻き、離すと緩みます。強い引きは緩め、落ち着いたら巻きます。ボタンにフォーカスした状態のEnterは巻く／止めるの切り替えです。
- スマホ: 小さい振りでキャストと合わせ、リールはタッチ長押し。ジャイロでの回転リールは未実装です。
- 「スマホで釣る」: 同じ海を操作するURLを表示。ローカルでは「別タブでコントローラーを試す」で動作を確認できます。
- 右上: 音の切り替え / 景色だけを見る。景色のみの表示からは画面の復帰ボタンかEscapeで戻せます。

初期設定は **127.0.0.1限定** です。別のスマホからlocalhostには接続できません。
実機のモーション入力には、両端末からアクセスできるHTTPS環境とセンサー許可が必要です。
外部公開、HTTPSデプロイ、スマホ実機での感度調整は今回の確認範囲外です。
オフラインでは海の表示用アセットを利用できますが、釣りの進行と同期にはサーバー接続が必要です。

## 検証

```powershell
npm run typecheck
npm test
# サーバー起動中に別のターミナルから実行
npm run test:ocean
npm run test:fish
npm run test:fishing
```

`test:ocean` は公開アセット、非公開パス、コントローラー接続、キャスト・着水・巻き戻し、連打・不正入力、切断時の状態を検証します。
`test:fishing` はWebSocket経由のキャスト・合わせ・張力調整・捕獲・再挑戦・合わせ損ね・押下更新切れを検証します。サーバー起動中に約一分かかります。別ポートでは環境変数 `OCEAN_URL` にURLを指定します。
`npm test` は早すぎる合わせ、糸切れ、無操作の失敗、複数の飛距離からの捕獲と二重計上防止を含む6テストです。

## 主な構成

- `client/App.tsx` / `client/useOceanSession.ts`: React UI、操作、モーション入力、接続、音
- `client/OceanCanvas.tsx`: React Three Fiberの描画ライフサイクル。海面シェーダーとGo/K8s魚の造形を再利用
- `client/waterShader.ts`: React本編で使う海面シェーダー
- `client/main.tsx` / `vite.config.ts`: ReactアプリのエントリーポイントとViteビルド
- `client/ocean.css`: 海とコントローラーのUIスタイル
- `go-fish.js`: Three.jsの魚モデル。React本編とプレビューで共有利用
- `k8s-fish.js`: Three.jsのK8s魚モデル。クラスタのポッド、リンク、ヘルムを造形
- `src/ocean-room.ts`: WebSocketルーム、20Hz同期、入力期限・接続管理
- `src/ocean-game.ts`: 海の釣りループ、張力・距離・捕獲判定
- `src/fish.ts`: 魚の移動モデル。`src/game.ts` は旧試作のゲーム進行
- `vendor/`: Three.js配布ファイルとライセンス

キャスト用ルームは最大128個、1ルーム8接続、無人になって30分後に回収されます。
ルームのURLは、その海を操作できる共有リンクです。第三者へ公開しないでください。
