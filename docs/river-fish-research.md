# 川魚モデルの調査と表現方針

## 設計の前提

ここにある魚は、各地の河川に共通する生物一覧ではなく、日本の河川資料を手がかりにした作品内の10種です。地域・季節・成長段階で生息状況は変わります。現実の魚の体つき・生態と、技術概念を魚の挙動へ翻訳したゲーム表現を分けて記載しています。

## 魚種と技術の対応

| 魚／技術 | 生物表現の根拠 | ゲーム内の技術表現 |
| --- | --- | --- |
| アユ／Go | 瀬に定位し藻を食べる。生活史の一部で海と川を移動する。 | 小群の個体が別々に反応してから流れに戻る。 |
| ヤマメ／Rust | 冷水性の上流魚。背部の黒点と体側の小判型パーマークが手がかり。ヤマメに朱点は基本的になく、朱点のあるアマゴと混同しない。 | 短い加速後に減速し、向きを切り替える。 |
| オイカワ／CSS | 浅瀬や速い流れを利用し、繁殖期の雄に婚姻色が出る。 | 体の輪郭を保ち、状態に応じた色の変化を控えめに見せる。 |
| ウグイ／Kubernetes | 上流から河口まで利用する魚。繁殖期の赤い側帯は季節変化として扱う。 | 群れの配置が流れに合わせて整い、負荷時に隊形が開く。 |
| カワムツ／JavaScript | 中上流の淵などを利用し、側面の縦帯が識別点になる。 | 小さい刺激へ短く反応し、切り返す。 |
| ナマズ／Docker | 中下流や岸際などの底層を利用し、口ひげを持つ。 | 低い姿勢で待ち、掛かると重く動き始める。 |
| ドジョウ／Python | 泥底で餌を探す。口ひげは10本あり、驚くと泥に潜ることがある。 | 全身へ伝わる柔らかい波で、底の狭い場所を抜ける。 |
| カマツカ／SQL | 中下流の砂・砂礫底で底生動物を探す。長い吻、下向きの口、1対の口ひげが識別点。 | 底をなぞって短く止まりながら餌を探す。 |
| コイ／Java | 緩流域・淵を利用し、口ひげと厚い体を持つ。 | 初動を重くし、旋回後も慣性を残す。 |
| ギンブナ／Linux | 緩い流れ、岸辺の植生帯や池などを利用する。 | 中層の安定した巡航と、小さな位置回復で基盤性を表す。 |

技術との対応は生物学的事実ではなく、プレイヤーが魚の形や泳ぎから概念を感じられるようにした創作上の比喩です。ゲーム用モデルは魚種ごとの体形・尾びれ・背びれ・模様を別に持ち、魚全体を同じ汎用メッシュにはしていません。

## 泳ぎの実装方針

- 体の進行方向・泳ぎの位相・振幅・旋回量をモデルへ渡し、尾側ほど大きく曲がる頂点変形を使います。
- 各魚は体形と曲がり始める位置、曲げ幅、旋回応答、ひれの遅れを変えます。細長い魚は全身波、底生魚は小さく低い動き、厚い魚は遅い旋回を選びます。
- 川魚10種は川の釣り場だけで抽選され、海の抽選には混ざりません。サーバーが水域を保持し、釣果後の魚種ローテーションも同じ水域に限定します。
- 魚種ごとの体形、尾側の曲げ始め、曲げ幅、旋回応答、ひれの位相遅れはモデルの泳ぎに反映されます。
- 現在のファイト中のライン抵抗・突進タイミングは川魚間で個別化されておらず、共通プロファイルです。表の「ゲーム内の技術表現」は図鑑の説明とモデルの泳ぎの方向性を示し、ファイト挙動の全てが固有実装済みという意味ではありません。
